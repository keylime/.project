# Security Policy

## Reporting Security Issues

The Keylime maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/keylime/keylime/security/advisories/new) form.

For more details, see the [Keylime security policy](https://github.com/keylime/keylime/blob/master/SECURITY.md).
